# DCS Events Portal

A centralized web portal built with **HTML** and **CSS** to display department and school-wide event schedules for students, provide announcement access, and streamline event management workflows for Computer Studies (CSS) officers.

---

## Overview

Scheduling conflicts, missed deadlines, and scattered updates across chats or notice boards often cause miscommunication between school administration, student leaders, and students. **DCS Events Portal** brings key dates, announcements, and event coordination details into a single, structured interface.

### Key Objectives
- **Centralized Schedule Visibility:** Give students one clear place to check upcoming Department of Computer Studies (DCS) and school-wide events.
- **Announcement Access:** Keep important notices, reminders, and schedule updates easy to find and read.
- **Officer Management Support:** Give CSS officers structured views and layouts to organize, track, and manage events and announcements without relying on fragmented messages.

---

## Core Features & Views

- **Event Calendar & Schedule View:** Displays department and school events with dates, times, venues, and event categories so students can plan ahead.
- **Announcements Feed / Panel:** Highlights timely notices, schedule changes, and officer updates.
- **CSS Officer Management Section:** Dedicated layout/controls for officers to review, organize, and manage event entries and announcements.
- **Responsive Layout:** Built with modern CSS layout techniques (such as Flexbox and CSS Grid) to stay readable and aligned across desktop and mobile screens.

---

## Tech Stack

- **HTML5:** Semantic structure for navigation, schedules, announcement cards, and officer management sections.
- **CSS3:** Responsive layout (Flexbox / Grid), typography, spacing, status badges, and visual hierarchy.
